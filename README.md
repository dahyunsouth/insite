<h1 align="center">Insite: 창업준비 플랫폼</h1>
<h3 align="center">FROM INSIGHT TO SITE - POWERED BY DATA.</h3>

> 도시데이터를 기반으로, 후보 상권을 비교·분석하고 수익성 예측 및 컨설팅까지 연계 가능한 플랫폼을 구축하여, 예비 창업자 및 상권 이전 희망자의 창업 실패 가능성을 최소화하고 데이터 기반 창업문화를 조성함을 목적으로 함

**참여인원**: 6명  
**수행기간**: 2025. 08. 25 - 2025. 10. 02 (7주)  
**수행배경**: 삼성청년SW·AI아카데미 2학기 특화 프로젝트
