## 전문가 리뷰 - 자기소개서 및 포트폴리오 차별화 전략
- 단순한 기술 경험 나열보다 문제 상황에서의 고민과 해결 과정을 깊게 보여주는 것이 효과적임
- 많은 지원자(심지어 경력직도)들이 문제 → 고민 → 해결 구조를 제대로 드러내지 않음
- 채용은 상대평가라기보다는 역할 적합성 평가에 가까움

### 차별화 방법
- 수치화: 문제 해결 전후의 변화를 수치로 표현
- 예시: 상권 조사 없이 창업 시 매출 X → 상권 조사 후 매출 Y

- 비즈니스 로직적 문제 정의: 단순 기술적 어려움이 아니라 사용자·비즈니스 임팩트로 연결

- 커뮤니케이션 과정 강조

- 진행 상황 공유 방식

- 팀 내 역할 및 협업 과정

- 모르는 부분을 어떻게 인정·학습·조율했는지

- 협업 경험 어필
- 단순 구현 사실이 아니라 타 직군과의 협업 방식 강조
- 예시: 백엔드와의 API 스펙 협의 및 연결
- 예시: 데이터 직군과 분석 결과를 시각화해 구현

- 이를 통해 “다른 직군과도 원활히 협업이 가능한 사람”이라는 신뢰 제공

### 주의할 점
- 서론이 길어지지 않도록
- 글의 흐름: 문제 → 고민 → 해결 → 결과(수치화) → 협업 과정
