## 3. npm vs. npx
    - npm: 패키지 관리자
        - 패키지를 설치하고 관리
        - 로컬이나 글로벌에 패키지를 저장
    - npx: 패키지 실행자
        - 패키지를 임시로 다운로드해서 실행
        - 실행 후 자동 삭제
    - npx는 항상 최신 버전 사용
    - npx는 디스크 공간 점유 x

## 5. React Query vs. 'fetch + useState'
- 사용자가 지도에서 여러 상권을 탐색할 때, 이미 본 상권을 다시 클릭하면, fetch 방식은 매번 로딩 보여주는 반면, React Query는 캐싱으로 즉시 보여주어 훨씬 부드러운 UX 제공
- 'fetch + useState'는 loading state, error handling, retry 로직을 매번 반복 구현해야 함. 각 컴포넌트마다 20-30줄의 보일러 플레이트 필요
    **- 보일러 플레이트란?**
        - 매번 반복해서 작성해야 하는 코드
        - useState 선언, useEffect 설정, try-catch 에러 처리, loading state 관리 등 본질적인 비즈니스 로직과는 별개임에도 불구하고 매번 써야 하는 부분
- 상권 정보가 업데이트되면, 지도, 목록, 차트 등 여러 컴포넌트가 동기화되어야 함. fetch 방식은 수동으로 각 상태 업데이트해야 하지만, React Query는 쿼리 무효화로 자동 동기화
