# Next.js, SSR/CSR, 그리고 인프라

- Next.js <- 무조건 SSR 아님
- 페이지, 컴포넌트 단위로 SSR, SSG, ISR, CSR를 섞는 하이브리드가 기본

### hook/event 사용 가능 여부
- 서버 컴포넌트
    - useState, useEffect, onClick 불가
- 클라이언트 컴포넌트
    - 파일 상단에 "use client" → hook/event 전부 가능

- 서버, 클라이언트 컴포넌트를 함께 쓰면 보통 SSR + 클라이언트 하이드레이션
- 순수 CSR이 필요하면 해당 조각만 ssr:false로 명시

- 이미지는 next/image로 최적화
- /api/…는 Route Handler로 내부화

- 서버 컴포넌트에서 브라우저 API(window, document) 사용 금지
